Lucarne

A self-hosted family calendar, chore tracker, grocery list and meal planner for a wall-mounted touchscreen.

Lucarne is open-source software that you run on your own hardware, such as a Raspberry Pi or a small PC behind a touchscreen. It shows your family's Google Calendars, chores, shopping lists and meal plans. Phones on the same home network can use it as a companion app.

Local-first and self-hosted. There is no Lucarne cloud service. Everything Lucarne stores stays in a database file on the device you run it on.

Google integration

If you choose to connect a Google account, Lucarne uses Google's APIs to:

  • show and edit events in the Google Calendars you pick, and
  • display photos you explicitly select with the Google Photos Picker as a screensaver.

See the privacy policy for exactly what is accessed and how it is handled.

Source code

Lucarne is MIT-licensed and available at github.com/el-dud3rino/Lucarne. Anyone running their own copy creates their own Google Cloud project and credentials.
